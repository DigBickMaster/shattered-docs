## Level 15–17 · element sets

From level 15 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 17.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Bastion Hammer | Bastion Hammer: Spark | Bastion Hammer: Decay |
| Frost | Doom Warden | Doom Warden: Hoarfrost | Doom Warden: Rime |
| Stone | Unbreakable | Unbreakable: Rubble | Unbreakable: Rock |
| Storm | Reflector | Reflector: Gust | Reflector: Peal |

## Level 20–23 · element sets

From level 20 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 22.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Bastion Hammer | Bastion Hammer: Ash | Bastion Hammer: Heat |
| Frost | Doom Warden | Doom Warden: Chill | Doom Warden: Glaze |
| Stone | Unbreakable | Unbreakable: Granite | Unbreakable: Obsidian |
| Storm | Reflector | Reflector: Thunder | Reflector: Squall |
