# Gear Catalog

## The way of gear

| Levels | What you wear |
| --- | --- |
| **1–4** | **Starting gear**, given as you level up: a weapon (Staff or Sword) and a Shirt at level 1, Trousers at 2, Boots at 3, Gloves at 4. |
| **5–12** | **The first subclass set** — one set per subclass, piece by piece. |
| **15–17** | **Element sets** — two sets for every path (subclass + element). Gear with a **socket**. |
| **20–23** | **Higher element sets** — two sets for every path. Gear with two sockets. |

## Set A and set B

From level 15 every path has two sets:

* **Set A** leans to **attack** — more elemental attack.
* **Set B** leans to **defence** — more elemental defence.

A **complete** element set gives a **set bonus**: from level 17 for the level 15 sets, from level 22 for the level 20 sets. The first subclass set has no full-set bonus.

## Slots

Head · Amulet · Torso · Belt · Bracers · Gloves · Legs · Feet · two Earrings · four Rings · Right hand · Left hand.

{% hint style="info" %}
The **belt** also opens your battle pockets — one pocket with a belt from level 5, three with a belt from level 15.
{% endhint %}
