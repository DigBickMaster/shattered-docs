## Level 15–17 · element sets

From level 15 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 17.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Flame Lord | Flame Lord: Spark | Flame Lord: Decay |
| Frost | Frost Lord | Frost Lord: Hoarfrost | Frost Lord: Rime |
| Stone | Stone Lord | Stone Lord: Rubble | Stone Lord: Rock |
| Storm | Storm Lord | Storm Lord: Gust | Storm Lord: Peal |

## Level 20–23 · element sets

From level 20 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 22.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Flame Lord | Flame Lord: Ash | Flame Lord: Heat |
| Frost | Frost Lord | Frost Lord: Chill | Frost Lord: Glaze |
| Stone | Stone Lord | Stone Lord: Granite | Stone Lord: Obsidian |
| Storm | Storm Lord | Storm Lord: Thunder | Storm Lord: Squall |
