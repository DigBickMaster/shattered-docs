## Level 15–17 · element sets

From level 15 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 17.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Crusher | Crusher: Spark | Crusher: Decay |
| Frost | Executioner | Executioner: Hoarfrost | Executioner: Rime |
| Stone | Raging | Raging: Rubble | Raging: Rock |
| Storm | Blade Whirl | Blade Whirl: Gust | Blade Whirl: Peal |

## Level 20–23 · element sets

From level 20 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 22.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Crusher | Crusher: Ash | Crusher: Heat |
| Frost | Executioner | Executioner: Chill | Executioner: Glaze |
| Stone | Raging | Raging: Granite | Raging: Obsidian |
| Storm | Blade Whirl | Blade Whirl: Thunder | Blade Whirl: Squall |
