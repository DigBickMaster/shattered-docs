## Level 15–17 · element sets

From level 15 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 17.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Hearth Healer | Hearth Healer: Spark | Hearth Healer: Decay |
| Frost | Spring Healer | Spring Healer: Hoarfrost | Spring Healer: Rime |
| Stone | Root Healer | Root Healer: Rubble | Root Healer: Rock |
| Storm | Spark Healer | Spark Healer: Gust | Spark Healer: Peal |

## Level 20–23 · element sets

From level 20 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 22.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Hearth Healer | Hearth Healer: Ash | Hearth Healer: Heat |
| Frost | Spring Healer | Spring Healer: Chill | Spring Healer: Glaze |
| Stone | Root Healer | Root Healer: Granite | Root Healer: Obsidian |
| Storm | Spark Healer | Spark Healer: Thunder | Spark Healer: Squall |
