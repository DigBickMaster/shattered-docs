## Level 15–17 · element sets

From level 15 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 17.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Seal Smith | Seal Smith: Spark | Seal Smith: Decay |
| Frost | Ice Keeper | Ice Keeper: Hoarfrost | Ice Keeper: Rime |
| Stone | Anchor Architect | Anchor Architect: Rubble | Anchor Architect: Rock |
| Storm | Storm Caller | Storm Caller: Gust | Storm Caller: Peal |

## Level 20–23 · element sets

From level 20 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 22.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Seal Smith | Seal Smith: Ash | Seal Smith: Heat |
| Frost | Ice Keeper | Ice Keeper: Chill | Ice Keeper: Glaze |
| Stone | Anchor Architect | Anchor Architect: Granite | Anchor Architect: Obsidian |
| Storm | Storm Caller | Storm Caller: Thunder | Storm Caller: Squall |
