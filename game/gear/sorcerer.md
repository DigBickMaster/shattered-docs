## Level 15–17 · element sets

From level 15 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 17.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Ash Mirage | Ash Mirage: Spark | Ash Mirage: Decay |
| Frost | Ice Mirage | Ice Mirage: Hoarfrost | Ice Mirage: Rime |
| Stone | Sand Mirage | Sand Mirage: Rubble | Sand Mirage: Rock |
| Storm | Mirage Weaver | Mirage Weaver: Gust | Mirage Weaver: Peal |

## Level 20–23 · element sets

From level 20 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 22.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Ash Mirage | Ash Mirage: Ash | Ash Mirage: Heat |
| Frost | Ice Mirage | Ice Mirage: Chill | Ice Mirage: Glaze |
| Stone | Sand Mirage | Sand Mirage: Granite | Sand Mirage: Obsidian |
| Storm | Mirage Weaver | Mirage Weaver: Thunder | Mirage Weaver: Squall |
