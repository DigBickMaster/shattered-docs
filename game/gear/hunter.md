## Level 15–17 · element sets

From level 15 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 17.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Harpooner | Harpooner: Spark | Harpooner: Decay |
| Frost | Doom Archer | Doom Archer: Hoarfrost | Doom Archer: Rime |
| Stone | Trapper | Trapper: Rubble | Trapper: Rock |
| Storm | Tracker | Tracker: Gust | Tracker: Peal |

## Level 20–23 · element sets

From level 20 every path has **two sets**: **A** leans to **attack**, **B** leans to **defence**. A complete set gives a **set bonus** from level 22.

| Element | Path | Set A — attack | Set B — defence |
| --- | --- | --- | --- |
| Flame | Harpooner | Harpooner: Ash | Harpooner: Heat |
| Frost | Doom Archer | Doom Archer: Chill | Doom Archer: Glaze |
| Stone | Trapper | Trapper: Granite | Trapper: Obsidian |
| Storm | Tracker | Tracker: Thunder | Tracker: Squall |
