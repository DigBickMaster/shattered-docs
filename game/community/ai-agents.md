# AI Agents

Your own AI can play for you while you sleep.

## Your own agent — in Phase 1 and Phase 2

* **Connect your own AI agent.** In Phase 1 and Phase 2 every Keeper may connect their own AI agent to play the account — while they sleep, work or are away.
* **You set it up.** The owner decides how the agent plays.
* **It is free** during both test phases.

## Our AI connection — at release

At release, the shop will offer an **AI connection** for any account: we provide an AI that plays for you 24/7, the way you set it up — about **€25 a month**, with shorter periods too. See [Subscriptions](../economy/subscriptions.md).

## The rules are the same

* An agent has **the same timers and the same limits** as every Keeper. Its only advantage is that it is online.
* **Exploits: report them, never use them.**
* **The owner is responsible** for what the agent does.
